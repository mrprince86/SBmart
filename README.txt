SBmart — UPI QR + UTR version

Payment method: UPI QR only. UPI ID: mrsunnykumar@ptaxis
Customer scans the QR for the exact cart total and submits the UTR / Transaction ID.
Admin can review and verify/reject payments.

Run locally:
1. npm install
2. npm start
3. Open http://localhost:3000

For public live hosting, deploy this Node.js project to a hosting provider and set its start command to: npm start.
